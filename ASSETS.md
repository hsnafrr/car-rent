# Asset manifest

Everything in `public/` except `logo.png` is generated by `npm run assets`.
Do not hand edit generated files; they will be overwritten.

---

## Masters

| File | Format | Notes |
| --- | --- | --- |
| `assets-src/hero-master.mp4` | 1280x720, H.264, 24fps, 121 frames, 5.04s, no audio | The cinematic hero film. Carries a single keyframe, which is why it is re-encoded rather than served directly |
| `assets-src/brio.mp4` | 1088x832, H.264, 24fps, 5.04s, with audio | Studio turntable, Toyota Agya or Honda Brio |
| `assets-src/avanza.mp4` | same | Toyota Avanza or Daihatsu Xenia |
| `assets-src/innova.mp4` | same | Toyota Innova Reborn |
| `assets-src/commuter.mp4` | same | Toyota Hiace Commuter |
| `assets-src/premio.mp4` | same | Toyota Hiace Premio |
| `assets-src/grandmax.mp4` | same | Grandmax Blindvan |
| `public/logo.png` | 631x612, opaque | Supplied brand artwork. Kept in `public/` because it is the master for the derived marks |

The six turntables ship with AAC audio tracks. The pipeline strips them: the
cards are decorative loops and the page never plays sound.

### Fleet cards

One set per vehicle slug, six sets in total, about 3.2 MB combined.

| Pattern | Size each | Purpose |
| --- | --- | --- |
| `fleet/<slug>.mp4` | 325 to 389 KB | Desktop loop, native 1088x832, CRF 30, no audio |
| `fleet/<slug>-mobile.mp4` | 111 to 137 KB | Mobile loop, 640 wide, CRF 32 |
| `fleet/<slug>.webp` | 22 to 40 KB | Poster, and the reduced motion still |
| `fleet/<slug>.avif` | 14 to 26 KB | Same frame, served first |

Slugs: `agya-brio`, `avanza-xenia`, `innova-reborn`, `hiace-commuter`,
`hiace-premio`, `grandmax-blindvan`.

**Paths are derived from the slug, not stored in the data.** `src/data/fleet.ts`
holds only facts; the card component builds `/fleet/<slug>.mp4` and friends. The
data and the files therefore cannot drift apart, but a slug rename means
renaming files too.

Unlike the hero these use a normal GOP (`-g 48`), because they play linearly on
loop rather than being seeked. All intra here would triple the size for no gain.

### Logo

| File | Size | Purpose |
| --- | --- | --- |
| `logo-mark.webp` / `@2x` | 3 / 8 KB | Header tile, the monogram cropped above the wordmark |
| `logo-lockup.webp` / `@2x` | 12 / 27 KB | Footer, the full supplied artwork |
| `favicon.png`, `apple-icon.png`, `icon-512.png` | | Derived from the same monogram crop |

The supplied artwork is a square lockup on an opaque dark navy bed: monogram on
top, then the wordmark, then "ESTABLISHED 2008". There is no transparency to
work with, so it is presented as a deliberate tile rather than pretending to be
a cutout. The crop was measured from the gold bounding box: the monogram
occupies y 66 to 339 and the type starts at y 375, so `LOGO_MARK_CROP` in
`tools/build-assets.mjs` takes 322 square pixels from (155, 44).

If a transparent version of the logo is ever supplied, replace `public/logo.png`
and re-run `npm run assets`. The crop constants may need adjusting.

## The WebM is optional

`hero-desktop.webm` is 5.0 MB, larger than the 3.6 MB MP4 at matched quality.
VP9 all intra is simply less efficient than x264 all intra, and all intra is
non negotiable for the hero because the video is seeked rather than played.

It is listed as the **second** `<source>`, so any browser that can play H.264
picks the MP4 and never downloads it. In practice that is every current
browser, so it costs visitors nothing, but it is roughly a third of the deploy.

To drop 5 MB from the deploy, delete the second `<source>` in
`src/components/Hero.tsx` and remove the WebM step from `buildVideo()` in
`tools/build-assets.mjs`.

## Replacing a fleet card film

1. Put the new file in `assets-src/`.
2. Point the slug at it in `FLEET_VIDEOS` in `tools/build-assets.mjs`.
3. Run `npm run assets`.

If the new film has a different aspect ratio, update `FLEET_CARD_SIZE` in
`src/data/fleet.ts` and the `aspect-ratio` on `.visual` in
`src/components/Fleet.module.css`. They are deliberately the same number in two
places so the layout reserves the right box before anything loads; keep them in
step or the cards will shift as they arrive.

Requirements: no audio needed, it is stripped anyway; a first frame that reads
well on its own, because it becomes the poster and the reduced motion still.

---

## Replacing the hero film

Drop the new master at `assets-src/hero-master.mp4` and run `npm run assets`.

If the new film is a different length or frame count, update these constants at
the top of `tools/build-assets.mjs`:

```
FIRST_FRAME   frame used for the loading poster
FINAL_FRAME   frame used for the reduced motion still and the CTA bed
OG_FRAME      frame used for the social card
```

`FINAL_FRAME` must be a frame with clear negative space on the left for the
headline and buttons.

If the beat timings change, update `BEAT_WINDOWS` in `src/components/Hero.tsx`
so the copy still lands with the right shot.

Requirements:

- 16:9
- No audio track, or it will be stripped
- No burned in text, logos, or watermarks
- Clean first and final frames
